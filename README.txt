# EMLMLP — site vitrine

Ce dossier contient une première version fonctionnelle du site de l'École Modèle des Langues Modernes et Leçons Particulières.

## Fichiers
- index.html : contenu et structure du site
- styles.css : design responsive
- script.js : menu mobile et formulaire de démonstration

## Important avant publication
1. Remplacer « À compléter » dans le pied de page par le vrai téléphone et l'e-mail.
2. Ajouter l'adresse exacte de l'école à Paris.
3. Connecter le formulaire à une adresse e-mail ou à un service de formulaires.
4. Ajouter le vrai logo et les photos de l'école.
5. Acheter un nom de domaine et un hébergement, puis envoyer ces fichiers sur l'hébergement.

Le formulaire actuel est une démonstration : il n'envoie pas encore d'e-mail.
